# Занятие 4 · Google Analytics 4

**Разобрали:** три уровня структуры — Analytics Account, Property, Data Stream;
создание аккаунта и ресурса, веб-поток, разница между числовым Stream ID
и Measurement ID вида `G-XXXXXXXXXX`.

**Сдаётся на паре:** `ga4_setup.md` — заполненный паспорт своего ресурса
и кадры экранов создания. Установка Google Tag и проверка Realtime —
следующее занятие.

**Домашнего задания по этому занятию нет.** Но заполненный `ga4_setup.md`
нужен дальше: Measurement ID отсюда ставится на сайт на занятии 5, и он же
используется в разделах про сверку и дашборд.

Кадры экранов GA4 кладите сюда же. На кадрах не должно быть чужих ресурсов
и адресов электронной почты других людей.
