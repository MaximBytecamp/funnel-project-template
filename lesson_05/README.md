# Занятие 5 · Свой сайт, Vercel и Google Tag

**Разобрали:** копия GitHub-шаблона через **Use this template**, клонирование
в VS Code, публикация на Vercel, обновление учебного потока GA4 под новый
адрес, установка Google Tag на три страницы, проверка Realtime с UTM-метками.

**Шаблон сайта:** https://github.com/MaximBytecamp/ga4-analytics-lab —
это отдельный репозиторий, не этот. Там HTML, CSS и JavaScript трёх страниц,
сборка и зависимости не нужны. Копию называют `ga4-analytics-lab-<фамилия>`.

**Сдаётся на паре:** `site.md` — адреса репозитория и сайта, Measurement ID,
подтверждение работы тега и кадр Realtime с определившимся источником.

**Домашнего задания по этому занятию нет.** Сайт остаётся рабочим до конца
дисциплины: на нём проверяются события, метки и данные для дашборда.

## Что где живёт

| Что | Где |
|---|---|
| код сайта | отдельный репозиторий из шаблона `ga4-analytics-lab` |
| адреса, идентификаторы, кадры проверок | этот репозиторий, `lesson_05/site.md` |

Код сайта в этот репозиторий не копируется: у него своя история и своя связь
с Vercel.
