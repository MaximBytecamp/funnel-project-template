## 3. Учебный поток GA4

Measurement ID берётся из `lesson_04/ga4_setup.md`, Website URL обновляется
под адрес с Vercel.

| Поле | Значение |
|---|---|
| Measurement ID (`G-…`) |  |
| Website URL в потоке |  |
| Страницы с установленным тегом | `index.html` / `about.html` / `contacts.html` |

Тег ставится на каждую страницу **по одному разу**. Две копии на странице
дают двойные события.

адрес стенда заменяется на адрес своего сайта.

| № | Ссылка целиком | `page_view` в Realtime | `ep.source` в Payload |
|---|---|---|---|
| 1 |  |  |  |
| 2 |  |  |  |

Источник и кампания из UTM в отчёте Realtime не показываются: эти измерения
вычисляются при обработке данных. Проверять метку нужно в Payload запроса,
а в Realtime смотреть только сам факт события.
