# Задание 1 · Путь данных от ссылки до заявки

По теме 1 «Цифровая воронка».

## Что сделать

1. Выбрать один сайт с формой заявки, заказа или записи.
2. Снять журнал событий: F12 → **Network** → фильтр `collect` → включить
   **Preserve log** → пройти по сайту до отправки формы. Записать **5 событий**
   с параметрами из вкладки **Payload**.
3. Построить схему воронки этого сайта: **от 4 до 7 этапов**.
4. Назвать **3 точки**, где данные могут потеряться или задвоиться.

Больше ничего не требуется. Настраивать сервисы и ставить счётчики не нужно.

## Как оценивается

| Что проверяется | Вес |
|---|---|
| 5 событий с реальными параметрами из Payload | 30% |
| Схема воронки на 4–7 этапов, этапы идут по порядку | 25% |
| 3 точки потери данных, каждая привязана к этапу схемы | 25% |
| Скриншоты приложены и соответствуют журналу | 20% |

Работа без скриншотов не принимается: журнал должен быть снят самостоятельно.
