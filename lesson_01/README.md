# Задание 1 · Путь данных от ссылки до заявки

По теме 1 «Цифровая воронка». Время на работу — 30–40 минут.

## Что сдать, коротко

1. Таблица: **три** действия на сайте и что при этом отправил счётчик.
2. Список: путь пользователя от ссылки до заявки, 5 шагов.
3. Одна строка: где по этому пути данные могут потеряться.

Всё в одном файле `homework_01.md`. Там уже готовы таблицы и заполненный
пример в каждом разделе — вы дописываете свои строки, а пример удаляете.

Сайт искать не нужно: он выдан ниже, в шаге 1.

## Как это сделать, по шагам

### Шаг 1. Откройте сайт из списка

Ссылки проверены: на каждой запросы счётчика видны в панели Network.
Берите первую, остальные — запасные.

| Сайт | Ссылка | Что там точно видно |
|---|---|---|
| Магазин сувениров Google (основной) | https://shop.merch.google/ | `page_view`, `scroll`, `view_promotion`, события при клике по товару и «Add to cart» |
| Хабр | https://habr.com/ru/ | `page_view` |
| Smashing Magazine | https://www.smashingmagazine.com/ | `page_view` |
| CSS-Tricks | https://css-tricks.com/ | `page_view` |

Берите **магазин Google**: счётчик там не спрятан, событий больше всего
и в корзину можно положить товар, ничего не покупая.

Два условия, без них строк не появится:

- браузер **Chrome** или **Edge** (в Safari и Firefox часть запросов режется);
- **блокировщик рекламы выключен** для этой вкладки — uBlock, AdGuard,
  щит Brave, «Защита от слежки». Обычно это иконка справа от адресной строки
  → выключить на этом сайте → обновить страницу.

Свой сайт вместо списка брать можно — но только если в фильтре `collect`
у вас реально появились строки. Пусто — возвращайтесь к списку.

### Шаг 2. Откройте панель разработчика

1. Нажмите **F12** (на ноутбуке может понадобиться **Fn + F12**).
2. Сверху в панели выберите вкладку **Network**.
3. В поле фильтра наберите `collect`.
4. Поставьте галочку **Preserve log** — иначе список очистится при переходах.
5. Обновите страницу. Должна появиться строка `collect?…&en=page_view`.

Строк нет — выключите блокировщик (шаг 1) или возьмите следующий сайт
из списка.

### Шаг 3. Сделайте три действия и запишите, что появилось

Ровно три, по порядку:

| Действие | Какое событие ждём |
|---|---|
| 1. Обновить страницу | `page_view` |
| 2. Прокрутить страницу до низа | `scroll` |
| 3. Нажать на любой товар (или на любую ссылку) | своё название — запишите, какое увидели |

После каждого действия в списке появляются новые строки. Нажмите на строку
→ вкладка **Payload**. Там список параметров, нужны два:

| Параметр | Что это | Пример значения |
|---|---|---|
| `en` | название события | `page_view`, `scroll`, `view_promotion` |
| `ep.*` | дополнительные данные события | `ep.source=vk` |

Третье действие может дать не одно событие, а несколько — запишите то,
которое появилось сразу после нажатия.

Три строки — в таблицу бланка.

### Шаг 4. Опишите путь пользователя

Пять шагов от ссылки до заявки — своими словами, без терминов.
Панель для этого не нужна: это рассказ о том, как человек доходит
до кнопки «Отправить». Пример в бланке уже заполнен.

### Шаг 5. Найдите точку потери

Одно место на этом пути, где данные могут не дойти. Пример в бланке
заполнен. Вторая строка — по желанию.

## Если не получается

| Что видите | Что делать |
|---|---|
| В фильтре `collect` пусто | Выключите блокировщик рекламы для этой вкладки и обновите страницу. Не помогло — следующий сайт из списка шага 1 |
| Панель не открывается по F12 | Правой кнопкой по странице → **Просмотреть код** → вкладка Network |
| Список сразу очищается | Не поставлена галочка **Preserve log** |
| Строк много и непонятно, какие нужны | Смотрите только те, что появились сразу после вашего действия |
| Вкладки Payload нет | Нажмите на строку запроса — вкладки появятся справа или снизу |
| `scroll` не появляется | Прокрутите до самого низа страницы: событие отправляется на 90% длины |
| Сайт на английском | Названия событий везде английские, переводить их не нужно |

## Как оценивается

| Что проверяется | Вес |
|---|---|
| Три действия записаны, названия событий настоящие | 40% |
| Путь из 5 шагов и точка потери | 40% |
| Два скриншота приложены | 20% |

Без скриншотов работа не принимается: по ним видно, что панель открывали сами.
